# Research Workspace Scope

## Use this repository for

- thesis/research context
- broader SUMO experiments
- security/authentication extensions
- demo/sustentation workflows
- supporting research references
- local documentation tooling

## Use ControladorSemaforicoTFC for

- the cleaner implementation-focused codebase
- core adaptive/fuzzy control
- SUMO integration
- FastAPI/web stack
- portfolio review of the software architecture

## Version-Control Policy

The workspace intentionally excludes:

- local AI/editor state
- thesis backup copies
- bundled third-party bibliography PDFs
- generated logs
- Python caches
- local environments
- model binaries
- generated video/output artifacts

## Security Policy

Authentication secrets and demo passwords belong in local environment configuration, not in committed source.

## Research Boundary

The repository contains simulation and software experiments. It does not claim production traffic-control certification or field deployment.
